# Fish, fish!

A gentle fishing game for young children. Tap the fish you want, watch it come to the bobber, and tap when it goes PLOP. Nothing can be lost or failed, and there are no ads, accounts, timers or purchases.

**Play:** https://innerloz.github.io/fish-fish-play/

This repository holds only the built game, which GitHub Pages serves. It runs in any modern browser with WebGL2 and falls back to a simpler version without it. Saves stay in the browser on your device.
